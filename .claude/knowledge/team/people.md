# Team — People

Reference file for team members relevant to UX workflows.
Update with real names, handles, and roles for your team.

## How to use

Load this file when a task involves notifying, assigning, or contextualizing feedback
from specific team members (e.g. feedback-digest, design-handoff notifications).

## Structure

Each person entry:

```
## Name
- Role: Senior UX Designer / Product Manager / Frontend Engineer / ...
- Figma handle: @handle (as it appears in Figma comments)
- Slack: @slack-handle
- Area: Checkout / Search / Onboarding / Design System / ...
```
