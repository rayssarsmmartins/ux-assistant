# Naming

- Commands: lowercase hyphenated workflow names — `design-handoff`, `design-system-audit`, `feedback-digest`.
- Skills: lowercase hyphenated capability names — `figma-context`, `ux-communication`, `accessibility-review`.
- Agents: lowercase hyphenated `<command-name>-<role>` names — `design-handoff-extractor`, `design-system-auditor`.
- References: lowercase hyphenated workflow names matching their command — `design-handoff`, `feedback-digest`.
- Runtime artifact paths: `/tmp/<workflow-name>/` (e.g. `/tmp/design-handoff/`, `/tmp/design-system-audit/<run_ts>/`).
- How-to files: zero-padded number + hyphenated title — `01-melhoria-em-tela-existente.md`.
